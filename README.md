Counter App 🔢

📌 Description

A simple and interactive Counter App built using HTML, CSS, and JavaScript that allows users to increase, decrease, and reset the counter value.

🎯 Purpose

The purpose of this project is to practice JavaScript functions, variables, DOM manipulation, and event handling by building a simple interactive web application.

🛠️ Technologies Used

HTML

CSS

JavaScript

✨ Features

Increase the counter value

Decrease the counter value

Reset the counter to zero

Simple and user-friendly interface

Responsive design



🚀 How to Run

Download or clone this repository.

Open the index.html file in a web browser.

Click the + button to increase the counter.

Click the - button to decrease the counter.

Click the Reset button to set the counter back to zero.
